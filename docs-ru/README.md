# Русская версия архитектурной документации Synanton

Каталог `docs-ru/` содержит русские версии архитектурных документов Synanton. Английские документы в `docs/` остаются каноническими источниками; перевод помогает читать их, но не заменяет исходный контракт.

## Что переведено и как соотносятся документы

Зеркало создаётся волнами. Для каждого переведённого документа сохраняется соответствующий путь относительно `docs/`, например:

| Английский источник | Русская версия |
|---|---|
| `docs/architecture/synanton-platform-architecture-1.0.md` | `docs-ru/architecture/synanton-platform-architecture-1.0.md` |
| `docs/architecture/synanton-design-1.32.md` | `docs-ru/architecture/synanton-design-1.32.md` |

Документ Design 1.24 отдельно не публиковался как архитектурный источник. Его проектный материал объединён с Design 1.25 в [`synanton-design-1.25.md`](../docs/architecture/synanton-design-1.25.md); русская версия этого единого документа будет находиться в `docs-ru/architecture/synanton-design-1.25.md`. Ссылки на проектный материал Design 1.24 ведут к этой объединённой версии. Отдельная русская заглушка для 1.24 не создаётся.

Нумерация разделов сохраняется. Например, Design 1.32 §55 в `docs/architecture/synanton-design-1.32.md` и §55 в соответствующем файле `docs-ru/architecture/synanton-design-1.32.md` обозначают один и тот же раздел. Перевод не перенумеровывает разделы и не меняет их идентификаторы.

## ADR остаются на английском

ADR-001–ADR-020 намеренно не переводятся. Код и pull request ссылаются на ADR по стабильным идентификаторам и цитируют их формулировки; английские версии обеспечивают однозначную проверяемость ссылок. Поэтому читатель русской версии, следующий по ссылке на ADR, попадёт на английский документ — это ожидаемое поведение.

Например, [ADR-020](../docs/architecture/decisions/adr-020-operation-partial-outcome.md) остаётся на английском. Значения `FULL` и `PARTIAL` сохраняются как идентификаторы; перевод архитектурных документов не создаёт отдельную русскую версию ADR.

## Источник и актуальность перевода

В front matter каждого переведённого архитектурного документа указываются SHA коммита английского источника и дата перевода:

```yaml
translated-from: <sha> @ <date>
```

CI проверяет, менялся ли английский источник после указанного SHA. Если проверка предупреждает об устаревшем переводе, используйте английский источник как авторитетный и не полагайтесь молча на русскую версию. Перевод обновляется отдельным просмотренным изменением с новым pin.

Этот каталог содержит только документационное зеркало. В него не входят переводы ADR, README проектов, документации по реализации, приёмочных документов или задач. Здесь также нет отдельного двуязычного сайта, поиска или переключателя языка.
