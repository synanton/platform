# Ontology and Semantic Mapping Glossary

**Status:** Current terminology for the ontology and cross-domain mapping research workstream  
**Source:** Domain Ontologies and Cross-Domain Semantic Mapping v0.3

| Term | Definition |
|---|---|
| Taxonomy | Hierarchical classification, usually based on `is-a` relationships |
| Ontology | Formal representation of concepts, properties, relationships and constraints |
| Lexical expression | A word or phrase found in a source |
| Lexical sense | A particular meaning of an expression |
| Concept | An ontology-owned semantic definition |
| Instance | An individual entity represented using ontology concepts |
| Context | Conditions relevant to interpreting an expression or assertion |
| Mapping | A governed semantic relationship between concepts |
| Mapping candidate | A proposed relationship awaiting evaluation or governance; not canonical knowledge |
| Governed mapping | A strategy-independent semantic assertion accepted through validation and governance |
| Mapping strategy | An algorithm or pipeline that generates, matches, scores or validates mapping candidates |
| Mapping strategy version | Immutable implementation/configuration identity for a strategy |
| Mapping experiment | A reproducible definition of a comparative research task |
| Mapping run | One execution of a mapping experiment |
| Mapping evaluation | Quality and operational results for a strategy or run |
| Mapping decision | Strategy-independent governance outcome referencing a candidate and promotion record |
| Mapping path | A composed path through governed mappings, subject to applicability and reasoning policy |
| Negative knowledge | Persistent rejected mappings, non-equivalence, disjointness, counterexamples and applicability exclusions |
| Promotion | Explicit audited operation converting a candidate into a governed mapping assertion |
| Determinism class | Declared reproducibility level: deterministic, seeded, best-effort reproducible or non-reproducible |

A taxonomy may form part of an ontology. A lexical expression is not itself a concept. A candidate, similarity score or analogy is not automatically a governed mapping or permission to infer.
