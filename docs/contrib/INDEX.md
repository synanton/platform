## How to Contribute to Documentation

1. For design changes: create a proposal in `../proposals/vX.Y/`.
2. For implementation plans: add or update files in `../implementation/`.
3. For operational docs: add runbooks to `../operations/runbooks/`.
4. All new directories must have an `INDEX.md`.
5. Update `../INDEX.md` if a new top-level section is added.
