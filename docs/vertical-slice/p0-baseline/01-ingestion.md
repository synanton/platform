## Unverified / unknown

- **Batch/folder upload is not implemented.** Only single-file multipart exists. Legacy `/ingest` can process a directory, but that is not upload. No multi-file endpoint/test found.
- **Format support is not enumerated by the platform.** Upload rejects missing/octet-stream MIME; actual format support is delegated to the extraction plane/Tika. EPUB and a full matrix are not verified.
- **External/cloud connectors are absent from this repo.** Only `file`, `upload`, and internal synvault adapters are visible.
- **No in-repo consumer or controller test for synvault manifest/content reads.** External Lucentrix usage is documentation-only here.
- **Kafka branch of legacy `/ingest` has no direct test found.**
- **MCP ingestion tool is a stub.** `IngestDocumentToolHandler` returns “ingest enqueued” without calling `/v1/ingestion-runs`.
- **No browser document-upload UI exists.** The only UI upload is ontology Turtle upload.
