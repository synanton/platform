## Findings

1. **Large-document relation cliff.** The short-doc canary accepted 8/12
   candidates (66.7%); this 104-page report accepted 0/564 (0%). This is a
   genuine quality/coverage finding, not a timeout or memory failure. It is
   consistent with the report's environmental/standards vocabulary falling
   outside the active enterprise ontology. The eval needs either ontology/rule
   coverage for this document class or an explicit large-document quality
   caveat.
2. **LLM large-document robustness failure.** The LLM adapter repeatedly emits
   malformed JSON for this document at different offsets. The pass cannot be
   compared until the parser/response length/chunking issue is resolved.
3. **Resource and timeout signals are acceptable.** Regex completed in ~5.1
   minutes (2.93 s/page), heap peaked at ~132 MiB, and no stage timeout fired.
   The regex path is not the resource-risk driver; relation validation is the
   dominant time.

## Decision

#724 remains open. The source requirement is satisfied and the regex resource
measurement is recorded, but the relation-quality cliff and LLM parse failure
must be resolved or explicitly carried as evaluation caveats before item 10 is
marked green.
