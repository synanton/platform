--------------

requires(MaintenanceSystem -> Component) before promotion, so regex ingestion
cannot by itself produce a same-canonical relation for this ontology. The V1
support row was therefore placed at the Cassandra promotion boundary. V2e is a
real producer-generated INVALID row: the extracted relation and active
resolutions were seeded, then the extraction evidence was removed so the real
validator returned EXTRACTED_EVIDENCE_NOT_FOUND. The deployed synflux producer,
deployed relix consumer, deployed relix promoter, and Neo4j writes are all live.
