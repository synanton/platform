# AI annotation proposals (candidates only)

Generated by `deepseek-v4.1-flash` via the OpenCode Zen provider. These are
**proposals, not gold labels**. None of these files may be imported into
`gold/` without human acceptance or correction.

Each `g7-dev-<id>.json` records the model/provider, prompt file, schema file,
generation timestamp, request ID, and raw result. `status.tsv` summarizes
structure, token usage, and proposal counts per document.

Human review, adjudication, and gold import remain pending.
